# My Daily C Practice Codes

This repository contains all the C programs I practice daily in college and at home.  
It includes simple examples like:
- Basic input/output
- If-else conditions
- Loops (for, while, do-while)
- Simple Interest calculation
- Factorial program
- Arrays and functions (coming soon)

## Purpose
- To keep track of my daily practice codes
- To share my learning journey with others
- To improve my coding skills step by step

## How to Run
1. Copy any `.c` file from this repository.
2. Paste it into an online compiler like [Programiz](https://www.programiz.com/c-programming/online-compiler) or run it using GCC.
3. Compile and execute to see the output.
